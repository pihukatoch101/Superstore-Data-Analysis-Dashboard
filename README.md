# 📊 Global Superstore Retail Performance Analytics

## 🚀 Project Overview
This project provides an end-to-end data analytics lifecycle breakdown of a global retail chain's performance using **51,000+ transaction rows**. The objective was to extract actionable financial insights, isolate high-performing territories, and uncover growth operational vectors by integrating **Excel**, **Python (Pandas)**, and **Power BI**.

---

## 🛠️ Tech Stack & Lifecycle Breakdown

### 1. Data Sanitization & Feature Engineering (Microsoft Excel)
* Checked for transactional integrity, processed data formatting, and verified duplicate boundaries across row IDs.
* * Engineered a strategic corporate metric: **Profit Margin Percentage** using the business formula:
  `Profit Margin = (Profit / Sales) * 100`


### 2. Exploratory Data Analysis (Python Pandas)
* Executed data manipulation inside Google Colab using multi-dimensional group-by structures.
* Programmatically derived aggregation models to track bottom-line revenues, shipping footprints, and operational product weights.

### 3. Business Intelligence & Reporting (Power BI Dashboard)
* Designed a clean, executive-ready dashboard showcasing financial performance.
* Implemented **Dynamic Category Slicers** to enable real-time parameter filtering across categories (Technology, Furniture, Office Supplies).
* Integrated standalone **KPI Indicators** for macro revenue health checks.

---

## 📈 Core Business Insights Extracted

* **Scale of Operations:** Total revenue analyzed sits at **\$12.64M**, generating a net global profit of **\$1.47M**.
* **Regional Growth Engine:** The **Central** market stands out as the primary net profit contributor, yielding over **\$311K**. Conversely, zones like Canada represent highly underutilized capacities that need operational overhaul.
* **Volume Footprints:** Linear scaling arrays show a persistent and aggressive Year-over-Year upward acceleration in customer sales transactions from 2011 through 2014.
